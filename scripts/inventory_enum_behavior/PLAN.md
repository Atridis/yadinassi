# Fresh enum persistence acquisition

Twelve source-owned raw observation groups, no expected behavior table and no
runtime parity claim. This is a new acquisition, not reuse of the language
namespace/type/metadata native16 contract.

1. Typed empty defaults and field metadata in catalog, document, lines and movements.
2. Catalog assignment, write and object reload.
3. Document header and line assignment, write and reload.
4. Wrong enum/scalar/Undefined assignments and wrong-type query parameter.
5. Explicit typed empty persistence in each admitted field location.
6. Posting enum dimensions/attributes without removing duplicate occurrences.
7. Typed raw catalog/document/line/register reads and equality/inequality parameters.
8. Enum equality joins and unmatched outer join NULL.
9. Enum grouping and distinct count, never enum ordering.
10. Balance, Turnovers and monthly combined statement with ordinary WHERE.
11. Staged rollback, changed enum dimension on repost, then unpost.
12. Durable value/type/empty reads in a second Enterprise process.

The controller must run 1–11, prove process exit and quiet census, then start a
new Enterprise process for 12 against the same owned infobase. An object reload
is not that restart witness. Both generated module inputs and verified module
bytes must be hash-bound, and both phase markers and exact case counts accepted.

The fixture preserves accepted stock declaration envelopes and their license
notice, adds complete enum declarations derived from the already accepted owned
enum source, and changes only declared field targets and the owned copy handler.
Material redump validation covers every field plus ordered enum declarations.
There are no forms, migrations, EnumRef resources, native UUID codecs, new
transaction authority, enum ordering, automatic unit arithmetic, or substitution
of authored State for Posted or AccumulationRecordType.

Future host profile: explicit `inventory-enum-v1`, fresh physical format16.
Its source/schema admission and host codec are separate from this native fixture.
Do not publish raw logs, credentials, locations or arbitrary native exception text.

# Independent inventory period acquisition

This is a raw observation packet, not a semantic golden or runtime parity claim.
It uses byte-identical owned reference inventory material from native12 but a new
observer, profile, host, bootstrap, isolated probe and branch-gated workflow.
The old acquisition and immutable observations are not changed.

Fourteen groups cover: empty typed columns, carry-only stock, exact start, exact
end, outside/zero-length boundaries, balanced flows and explicit zero resource
rows, decimal/multiple resources, reference identity/rename, partial days,
partial months across leap/year boundaries, gaps/carry completion, repost/unpost,
outer-transaction staged catalog reference and rollback, max date 9999.
Both Turnovers and BalanceAndTurnovers Day/Month are measured. Group8 is typed
reference grouping only: this fixture has no scalar dimension, so it cannot
establish scalar collation parity. Existing scalar evidence remains separate.

Query field names and metadata accesses are probes, not presumed successful
contracts. A failed group is retained as a bounded diagnostic with no fabricated
observation; full capture requires all fourteen groups. Only subsequent measured
results can authorize runtime behavior or an immutable replay golden.

Execution gate: offline preparation suite collection count must be announced
before tests. Actual native acquisition requires a separate root notice for
fourteen groups, frozen source and approved branch PR trigger. No manual Docker
or alternate image path. The copied isolation harness keeps the pinned image,
non-root networkless container, no host database, exact source/host/runtime
binding, install + UpdateDBCfg + material redump, bounded output and process /
container cleanup gates. Publishing the branch alone does not trigger capture.

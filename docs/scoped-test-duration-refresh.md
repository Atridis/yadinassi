# Обновление истории времени тестов

`python -m scripts.refresh_test_durations --reports DIRECTORY --source SOURCE_SHA --run RUN_ID --output scripts/test_durations.json --scope required-platforms`

По умолчанию сохраняется строгий режим `full-four`. Явный режим `required-platforms` принимает только полный успешный heavy-premerge набор платформ, предусмотренных политикой данного события. Он вызывает неизменённый `coverage(binding, reports, True)`; отсутствующие, лишние, смешанные или неуспешные разделы не допускаются. Это не утверждение о покрытии исключённой mac-arm.

CLI всегда создаёт sidecar `OUTPUT.audit.json` с точным binding, областью покрытия, SHA256 отчётов и выходного файла. В репозитории sidecar хранится как `scripts/test_durations.audit.json`. Сама история остаётся schema 1; интерфейс partitioner не меняется.

Времена отражают отдельные исполнения тестов, а не setup/teardown модульных и классовых fixtures. Этот недостающий overhead не распределяется искусственно. Fixture-only skips имеют нулевой вес, но перечислены отдельно в аудите и не считаются измеренными исполнениями. Группировка fixtures остаётся прежней. Неизвестные истории тесты не исключаются из обнаружения или покрытия.

# Прямой Python: первый этап поддержки меток и Перейти

Поддержаны неиспользуемые метки и безусловные переходы к метке **в том же
списке операторов**. Регистр имени метки несущественен. Например:

```bsl
Функция Пример()
    Счетчик = 0;
    ~Повтор:
    Счетчик = Счетчик + 1;
    Если Счетчик = 10 Тогда
        Возврат Счетчик;
    КонецЕсли;
    Перейти ~Повтор;
КонецФункции
```

Переходы разрешаются при генерации. Для одного списка их граф состоит из
достижимого префикса и, возможно, цикла: префикс становится обычными операторами
Python, цикл — `while True`. Нет таблицы меток в runtime, диспетчера инструкций,
рекурсивного исполнения, стороннего декоратора или перехода на legacy.
Недостижимые операторы не исполняются и не генерируются. Программы без переходов
не получают синтетических циклов. Все исходные переходы, включая недостижимые,
проверяются до выполнения программы.

Это **не полная поддержка Перейти**. Явная ошибка компиляции пока выдаётся для:

- перехода из вложенного `Если`, цикла или `Попытка` к внешней метке;
- цикла переходов с `Прервать`/`Продолжить`, адресованными окружающему BSL-циклу
  (нельзя позволить синтетическому циклу перехватить их);
- объявления `Перем` внутри цикла переходов;
- чтения потенциально ещё не инициализированного локального имени, совпадающего
  с именем процедуры/функции, внутри цикла переходов.

Обычные вложенные циклы сохраняют собственные `Прервать`/`Продолжить`.
Локальные переходы внутри тела `Попытка` или внутри его обработчика допустимы;
переход между ними или наружу пока не поддержан. Ошибки не скрываются fallback.
Анализ прямолинейных типов/коллекционных префиксов не переносит свои факты через
неподдерживаемые им рёбра: для программы с переходами коллекционные префиксы
отключены на этапе компиляции. Чтение пропущенного локального присваивания не
получает выдуманное значение; формат ошибки неунифицированного отсутствующего
локального имени остаётся текущим ограничением прямого Python.

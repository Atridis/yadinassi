# Прямой Python: метки и Перейти

Поддержаны метки и переходы к метке **в том же списке операторов** или
**во внешнем активном списке** того же модуля или процедуры/функции. Регистр имени метки несущественен. Например:

```bsl
Функция Пример()
    Счетчик = 0;
    ~Повтор:
    Счетчик = Счетчик + 1;
    Если Счетчик = 10 Тогда
        Возврат Счетчик;
    КонецЕсли;
    Перейти ~Повтор;
КонецФункции
```

Переходы разрешаются при генерации. Для одного списка их граф состоит из
достижимого префикса и, возможно, цикла: префикс становится обычными операторами
Python, цикл — `while True`. Для внешнего перехода только активный список с
целевой меткой получает локальный цикл по своим сегментам. Вложенный переход
покидает обычные Python-блоки и возвращает управление нужному сегменту. Он не
вызывает BSL-обработчик ошибки, пропускает инкремент покинутого цикла и не меняет
адрес назначения `Прервать`/`Продолжить` оставшегося цикла. Выход из обработчика
освобождает его контекст как обычное завершение блока. Код без `Перейти` не получает
новых ветвей, циклов или проверок. Нет перехода на другой движок или единого
диспетчера инструкций.

Все переходы, включая недостижимые, проверяются до выполнения. Вход во
вложенный/соседний блок и переход через границу модуля, процедуры/функции или
динамического фрагмента остаются запрещены. Это границы текущего проекта,
а не утверждение о запретах нативной платформы.

Явная ошибка также сохраняется для некоторых сочетаний с `Перем` и затенением
имени процедуры/функции: генератор пока не вычисляет состояние инициализации для
этих переходов. Цикл безусловных переходов в одном списке по-прежнему не может
перехватить `Прервать`/`Продолжить` из окружающего BSL-цикла. Оптимизация типов
и коллекционных префиксов не переносит свои факты через переходы.

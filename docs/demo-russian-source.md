# Русский исходный текст основной демо

`examples/demo` использует русский синтаксис BSL: ключевые слова, директивы
контекста, основные глобальные функции и конструкторы. Имена обработчиков,
параметров и свойств, на которые ссылаются формы и тестовые контракты, сохранены.
Имена метаданных `Receipt`, `Issue`, `Stock` и их UUID также не переименованы:
русские пользовательские представления задаются синонимами и заголовками форм.
Поступление и списание остаются разными типами документов со своими модулями.

Подсистема «Нормативная информация» содержит только три справочника. Документы
и регистр не добавляются в неё искусственно. Технические общие формы остаются
техническими примерами, а не новым типом бизнес-операции.

Изменён текущий точный source allowlist основной демо и входной manifest
Designer-проверки. Старые native captures не менялись и не доказывают проверку
нового исходника. Для новых XML/BSL нужен новый Designer create/load/check/update;
локальные тесты не означают Enterprise parity. Закрытые исторические профили
импорта не расширены. Пассивные русские синонимы снимаются только в private
проекции текущего hash-bound main-demo source для старого scalar schema parser.

Сохранённые базы со старым exact-source демо не получают новые байты автоматически.
Создавайте отдельную тестовую базу из нового XML либо используйте явно разрешённый
процесс обновления конфигурации; не подменяйте source-хэши внутри существующей базы.

# Вызовы между модулями в автономном запуске

Для запуска BSL-файла без БД CLI разрешает связывать обычные функции из
файловых импортов один раз, при первом исполнении места вызова. Объявление
импорта по-прежнему инициализирует файл как раньше. Неисполненная ветка
не разрешает имена функций и не создаёт точку вызова.

При простых аргументах (имя или литерал) связывается экспортированная
клиентская функция со всеми переданными параметрами по значению, если
сгенерированная функция не замыкается на состояние или контекст модуля.
Результат связывания хранится только в конкретном запуске. На следующих
вызовах нет повторного обхода пространства импорта или открытия контекста
модуля; ошибка по-прежнему указывает на BSL-файл функции.

Импорты со ссылочными параметрами, внешними вызовами, динамическим
исполнением или зависимостью от состояния модуля идут через существующие
границы прямого движка. Режим встраивания в Python, REPL, конфигурации и
запуск с БД не меняются. `--emit-python` показывает код автономного
запуска, не читая и не исполняя импортируемые файлы.

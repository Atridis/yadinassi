# Замеры Python и BSL

Из корня репозитория:

```sh
python scripts/benchmark_execution_layers.py --iterations 100000 --rounds 9 > layers.json
python scripts/benchmark_extended_layers.py --iterations 64 --rounds 5 \
  --output extended.json --summary extended.md
```

Оба сценария принимают `--case` (можно повторять) и `--bsl-route default|prepared`.
`default` использует обычный API, `prepared` измеряет повторное исполнение
заранее подготовленного плана. Не у всех операций, например открытия формы,
есть подготовленный вариант. Расширенный JSON отдельно содержит время
подготовки, первого исполнения и повторных замеров. Профили времени не
стоит смешивать между режимами.

Сравнивайте Python и BSL при одинаковых данных, числе операций и границах
замера. Отчёт расширенного прогона показывает Python-референс и BSL; профили
«Запросы» и «Все команды» разделены. Второй счётчик включает также PRAGMA и
команды транзакций. Ни один счётчик сам по себе не объясняет время:
проверяйте фактическую трассу SQL и код референса.

Для сравнения двух версий запускайте их на той же машине, в той же версии
Python и с одинаковыми аргументами. Тесты проверяют результаты сценариев,
но не требуют, чтобы одна версия оказалась быстрее другой.

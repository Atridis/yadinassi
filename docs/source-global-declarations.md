# Отложенная компиляция глобальных общих модулей

При поиске глобальной экспортной процедуры source-host строит индекс
объявлений доступных на текущей стороне общих модулей. Штатный lexer
обрабатывает строки, комментарии и выбранный профиль препроцессора;
штатный parser проверяет заголовки и границы объявлений. Для индекса
тела процедур заменяются пустыми, но не выполняются.

Это позволяет вызвать рабочую глобальную функцию, даже если **другой,
неиспользуемый** общий модуль содержит синтаксис тела, который пока не
поддерживается. При выборе модуля он по-прежнему компилируется полностью:
ошибка любого его тела возвращается с исходным путём/позицией.
Повреждённые заголовки, лексически неразбираемые файлы и незавершённые
границы не угадываются и могут блокировать построение индекса.

Дублирующие экспорты остаются ошибкой неоднозначности, в том числе если
одно из тел содержит ошибку. Private-функции не становятся глобальными.
Локальные процедуры и переменные сохраняют приоритет. Проверки стороны,
Global/ServerCall/Privileged, безопасного режима и семейства исполнения
не ослабляются. Строгий ConfigurationApplication не использует этот индекс.

Тесты: `test_source_global_declarations.py` плюс существующие source
startup/global/application-export/ServerCall проверки. Нативная parity
данного source-only режима не заявляется.

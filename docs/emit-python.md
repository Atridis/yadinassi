# Экспорт Python-кода без исполнения BSL

```console
yadinassi example.bsl --emit-python generated
python -m yadinassi "Пример с пробелами.bsl" --emit-python generated
```

Режим принимает **один существующий файл**, подготавливает его обычным
`python-direct` и записывает `DIRECTORY/<stem>.py` в UTF-8. Папка создаётся
при необходимости. BSL не исполняется: сообщения, обращения к файлам,
обработчики и серверные инициализаторы не вызываются. База данных и UI не
запускаются. Обычный запуск без `--emit-python` не изменён.

Это исходный текст реально используемого компилятором плана из
`Interpreter.prepare`, а не дизассемблирование и не отдельный bare-генератор.
Подготовка создаёт Python-функции, но не вызывает их BSL-тело. Проверки и
преобразования компилятора совпадают с обычным исполнением.

## Что лежит в файлах

Основной файл содержит функцию сгенерированного модуля. Если подготовка этого
же файла создала дополнительные планы, рядом записываются:

* `<stem>.server.py`: серверные подпрограммы;
* `<stem>.server-nocontext.py`: серверные подпрограммы без контекста;
* `<stem>.dual-client.py`: клиентский план двойных подпрограмм;
* `<stem>.server-init.py`: серверный инициализатор.

Записываются только существующие планы. Клиентские подпрограммы уже находятся
в основном файле. Это v1 для одного входного BSL, **не экспорт проекта**:
`#Импорт` остаётся обязанностью runtime; файлы импортов не читаются и не
обходятся. Код, создаваемый позднее динамическим исполнением, также не входит
в экспорт. Поэтому успешный экспорт не проверяет существование импортов или
все условия будущего исполнения.

**Файл диагностический, не самодостаточный.** В нём могут быть ссылки на
`_constants`, runtime helpers, namespace и контекст выполнения. Экспорт не
сериализует их, не добавляет загрузчик и не обещает запуск через `python
generated/example.py`. Его назначение: прочитать результат трансляции,
сравнить операции и найти лишние вызовы.

## Опции и ошибки

* Поддерживаются `--encoding` (вход, по умолчанию `utf-8-sig`) и
  `--preprocessor-profile`; выход всегда UTF-8.
* `-c`, stdin (`-`), legacy backend, режимы базы/источника/UI несовместимы с
  `--emit-python` и отклоняются до их запуска.
* При синтаксической или неподдерживаемой конструкции возвращается ошибка,
  без скрытого перехода на legacy и без частичного экспорта.
* Существующие выходные файлы не перезаписываются. Проверяется также
  совпадение имён без учёта регистра, в том числе на Linux, чтобы не получить
  конфликт на Windows. Зарезервированные Windows-имена вроде `CON.py`
  отклоняются. Для повторного экспорта выберите другую папку.
* Код завершения: `0` при успехе, `1` при ошибке чтения/компиляции/записи,
  `2` при неверной комбинации аргументов.

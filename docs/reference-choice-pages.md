# Страницы и поиск ссылок в формах

Catalog picker в конфигурационном UI снимает полный ограниченный список
непомеченных записей: до 8192 строк и 4 MiB данных code/description с резервом
на ключи. Чтение закрывается до ожидания пользователя. На экран выдаются
32 строки, непрозрачные токены выбора и не более двух курсоров навигации.
Ни UUID записи, ни backend continuation не передаются браузеру.

Поиск без учёта регистра выполняется по коду и наименованию в сохранённом
снимке. Пустой запрос возвращает все строки снимка. Exact code отдельно
перечитывает только точные совпадения; последующий общий поиск заново снимает
полный список. Это host UI semantics, не утверждение о native choice events
или региональной сортировке платформы 1С.

Если полный снимок превышает бюджет, возвращается `snapshot_limit`, пустые
rows и `navigation=null`. Это не пустой результат и не усечённый список:
общее количество неизвестно. Пользователь может сузить отдельное чтение
точным кодом. Перечисления сохраняют прежний протокол без страниц.

Каждая смена страницы или фильтра отзывает прежние choice/cursor tokens.
Проверки владельца формы, объекта, конкретной строки таблицы, текущего
значения и источника конфигурации сохраняются. Apply повторно читает запись:
удалённую либо помеченную запись нельзя принять из устаревшего снимка.
Ошибка чтения или wire preflight не превращается в успешный выбор и не
разрешает повторную запись. Cancel оставляет значение без изменений.

Это расширение конфигурационных форм, не legacy catalog-only `<select>`
и не фильтры отчётов. Оно не расширяет generic reference codecs, grants
импорта либо виды поддерживаемых ссылок.

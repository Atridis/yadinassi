Linux/UTC native capture and compares its exact bytes with a separate interpreter

- StandardName: `Центральноевропейский (зима)`
- DaylightName: `Центральноевропейский (лето)`
- BaseUtcOffset: `01:00:00`
- SupportsDaylightSavingTime: `True`

The exact Windows identifier is **Central European Standard Time**, not
Central Europe Standard Time. Unicode CLDR maps its global (`001`) and Polish
(`PL`) entries to `Europe/Warsaw`:
[official Windows timezone mapping](https://github.com/unicode-org/cldr/blob/release-48/common/supplemental/windowsZones.xml).
This is the replay mapping for this fixture, not a claim that Windows and IANA
historical rules are identical at every date. A fixed `+01:00` offset is not an
adequate replacement for this seasonal timezone. The production interpreter's
host-local policy is separate from the recorded test environment.

Fixture replay uses `YADINASSI_TIMEZONE=Europe/Warsaw` and bundled
`tzdata==2026.5` (IANA `2026e`). This changes only the execution environment;
all output bytes remain compared without timezone normalization.

- `T`: `Table.Count`, ordered `Table.Names`, ordered `Table.Rows`. Every mutation
  reports `Status`, T and `Result`, including all 21 error-status cases. Failure
  does not skip the post-operation state. Full repeated descriptor metadata is
  intentionally removed from operations whose purpose is row/cell behavior;
  names, order, counts and every cell remain observable.
- `C`: column `Name`, `Title`, `Width`, exact scalar `ValueType` representation.
  C is retained for direct column reads, added/inserted column results, and all
  rename/title/width/read-only-type setter cases, including failures.
- `R`: compact `Result` view: row cells; table Count/Names/Rows; column C; otherwise
  the original scalar/structure. Copy results additionally retain `ResultSchema`
  (ordered C records), preserving type/title/width/name copying observations.
- `L`: `Owner`, `SameRow`, `SameColumn`, `Status`, `After.Count/Names/Rows`, `Extra`.
  The repeated immutable initial `Before` baseline is represented once by
  `table.codec.table.View` and its exact Write, with schema fields also observed
  in `table.codec.columns.View`. Each link helper still starts from the same
  `НоваяТаблицаПробы`. After-state and scenario-specific Extra remain independent.
- `K`: `Type`, `Text`, compact `View`, exact raw `TypeWrite`, independently read
  `TypeRead.Type/Equal/Stable`, exact raw `Write`, `ReadType`, `ReadView`, `Equal`.
  `ReadWrite` is `same-as-Write` only when byte-equal to retained Write; otherwise
  its exact bytes remain. `Nested.Write` retains the exact array-wrapped raw

  preserve nested inverse behavior under the same exact-bytes/equality rule.
- `D`: all four `Default`, `Status`, `Assigned`, `Total` fields remain unchanged
  semantically. No typed case is coalesced, including superficially similar totals.
- Constructor probes now observe Type/Text/View; duplicate empty codec streams
  formerly emitted by both constructor aliases are represented by `codec.empty`.
  The aliases and each invalid constructor remain separate protected calls.

#### Output grammar and readability

The original `table.<label>: [` header and closing `]` remain. Structured fields
are printed on separate lines with a dot path (`Table.Count`, `Nested.Write`).
Arrays preserve element order and use semicolon delimiters; nested structures
retain explicitly encoded keys. Scalar values use their native internal scalar
representation. Before printing a scalar representation, backslash is doubled,
then CR/LF/TAB become `\r`, `\n`, `\t`. Native quoted-string delimiters remain,
so embedded delimiters, quotes, literal escape sequences, Unicode surrogate
escapes and actual newlines are distinguishable. Field paths come only from
fixed test-owned field names, not arbitrary input strings.

The verified compact native output is 2,394 lines / 68,412 UTF-8 bytes overall,
including the unchanged 1,451-line prefix. It matches the local replay in full.
Reduction removes duplicated semantic scaffolding and stream copies rather
than merely joining the original 12,988 lines.

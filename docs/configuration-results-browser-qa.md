# Проверка результатов дочерних форм

Отдельный пример и его reviewed browser workflow заменены сценариями основной
конфигурации `examples/demo`. См. [перенос recovery](main-demo-owned-results-recovery.md).

Проверены штатное завершение и запрет закрытия, независимый несохранённый черновик,
двойное нажатие при задержке ответа, потеря уже подтверждённого закрытия и инспекция
без повторения команды. Исторические результаты старого harness относятся только
к сохранённым в Git исходным коммитам и не являются доказательством новой демо.

Актуальный entrypoint: `tests/browser_ui/main_demo_browser_qa.mjs`, workflow
`.github/workflows/main-demo-browser-qa.yml`. Проверки sandbox, точного source binding,
ограничений времени и сети остаются обязательными. Это browser, не native evidence.

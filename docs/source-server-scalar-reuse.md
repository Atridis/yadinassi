# Повторное использование скалярных результатов source ServerCall

Source-host поддерживает ограниченный локальный контракт `DuringSession` и
`DuringRequest` для серверных общих модулей с `ServerCall=true`. Это интеграция
существующего измеренного runtime, не эмуляция кластера или полной платформы.

Модуль должен быть только серверным, неглобальным и непривилегированным, без
OrdinaryClient/ExternalConnection. Все его функции, включая private helpers,
синхронные; параметры явно Val/Знач без значений по умолчанию. Процедуры и
асинхронные функции в таком модуле отклоняются. Входы и результаты ограничены
существующим scalar packet codec; массивы, структуры, UUID и ссылки не получают
новых транспортных разрешений. Неиспользованный несовместимый модуль сохраняется
в source; ошибка возникает при его использовании.

Вызовы одного такого модуля с клиентской и серверной стороны используют одну
application-owned cache identity. DuringSession сохраняется до refresh/close и
обычных границ существующего кэша. DuringRequest принадлежит внешнему синхронному
запросу интерпретатора: вложенный ServerCall не создаёт новый request cache.
Новый внешний execute получает новую request область, также после исключения.
Это локальные границы host, не заявление о native сетевом сеансе.

До cache lookup сохраняются проверки перехода SafeMode/транзакции; чужая семья,
закрытое приложение или активное асинхронное продолжение не получают cache hit.
Refresh сохраняет epoch semantics, а private/unqualified вызовы не становятся
автоматически cached. Скалярные ограничения действуют и при same-side вызове
функции этого ServerCall-модуля, поэтому смена пути не обходит admission.

Существующий same-side source reuse модулей без ServerCall не меняется и не
получает новых прав crossing. Client-only reuse также остаётся прежним.

Локальные тесты повторяют два события существующего native witness
`43165393593`: первые15 наблюдений в одной внешней границе, последнее в следующей.
Исходный fixture/observer не подменяется. Это source integration replay, а не
новый native прогон произвольной конфигурации или полная совместимость БСП.

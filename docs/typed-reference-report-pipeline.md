# Типизированный обмен результатами ссылочных запросов

Этот блок расширяет **host-контракт отчётов**, а не форматы хранения или
сериализацию ссылок. Поддерживаются одиночные домены CatalogRef/DocumentRef;
перечисления и их пакетные запросы сохраняют прежние ограничения.

```bsl
Q = New Query("SELECT Ref AS Item, Category, Amount FROM Catalog.Products");
Input = Q.Execute().Unload();
Q.SetParameter("Input", Input);
Q.Text = "SELECT Item, Category, Amount INTO Prepared FROM &Input;
|SELECT C.Code AS Category, SUM(T.Amount) AS Total
|FROM Prepared AS T JOIN Catalog.Categories AS C ON T.Category=C.Ref
|GROUP BY C.Code";
Report = Q.Execute().Unload();
```

Пример требует соответствующих метаданных Products/Categories. Ссылка сохраняет
точный тип и владельца, включая пустой результат. NULL после внешнего соединения
остаётся NULL, не превращаясь в пустую ссылку. TypeDescription колонки результата
показывает один ссылочный тип и NULL; это внутреннее описание результата, а не
разрешение на публичное конструирование составных типов.

## Граница владения

Колонка хранит привязку к каноническому менеджеру, metadata snapshot и контексту.
UUID сам по себе не доказывает владение. При загрузке внешней таблицы проверяются
все колонки и значения, включая неиспользуемые и отфильтрованные; callback ссылки
должен принадлежать исходному менеджеру. Параметр копируется один раз на Execute,
до чтения базы. Последующие изменения исходной таблицы не меняют результат или
зафиксированные временные таблицы.

Reference-bearing внешние и временные входы требуют одного общего owned query
read view, даже без постоянного источника в тексте запроса. В нём проверяются
идентичность базы, поколение и схема всех ссылочных доменов. Постоянные источники
используют тот же view. Проверка не читает объекты по ссылкам и не проверяет
существование каждой записи. Scalar-only внешние запросы не приобретают view.
Выгрузка, просмотр metadata и присваивание ячейки не открывают view.

Все изменения менеджера временных таблиц публикуются только после успеха всего
пакета и закрытия view. Ошибка схемы, бюджета, выполнения или закрытия сохраняет
прежнее состояние менеджера.

## Что намеренно не добавлено

- Add/default в выгруженной nullable таблице, автоматическое создание пустых
  ссылок, присваивание NULL и преобразование String/UUID/другого домена.
- Общая поддержка произвольных ссылочных колонок ValueTable. Допустимо только
  точное ссылочное присваивание уже существующей ячейке результата запроса.
- Reference codecs, ValueStorage и client/server transfer/capture.
- Полиморфные ссылочные домены, новые записи через Query, новые права записи.
- Native-паритет default/coercion/lifetime: этот контракт требует собственной
  проверки и не выводится из старых измерений скалярных результатов.

Существующие лимиты строк, ячеек, текста и пакетов сохраняются. Snapshot данных
не является долгоживущей арендой базы или разрешением использовать чужой контекст.

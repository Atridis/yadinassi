# FindRows: линейный поиск и ленивые индексы

`FindRows` / `НайтиСтроки` возвращает исходные строки в порядке таблицы,
а не копии. Пустая структура фильтра возвращает пустой массив. Неизвестное
поле фильтра считается ошибкой.

`T.Indexes.Add("K,V")` объявляет набор колонок, но не строит индекс при записи.
Совпадающий набор полей фильтра использует ленивый индекс независимо от порядка
полей. Изменения строк или схемы обновляют или инвалидируют соответствующее
состояние. Ветки, где индекс неприменим, используют обычный поиск.

Проверки живых ссылок, порядка, изменений колонки и повторного поиска находятся
в `tests/test_linear_find_rows.py`. Сравнить поиск с индексом и без него можно
скриптом `benchmarks/find_rows_linear_lazy.py`: он использует рабочий
`Interpreter()` и подготовленный BSL в обоих случаях.

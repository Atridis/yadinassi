# XDTO-пакеты в source-режиме

Source-host связывает глобальную `ФабрикаXDTO` / `XDTOFactory` с объявленными
пакетами загруженной XML-конфигурации. Это отдельный локальный контракт,
не утверждение полной совместимости source-host с платформой 1С.

`Тип(namespace, name)` лениво загружает выбранный пакет и замкнутую цепочку
его локальных импортов. Неиспользованный неподдерживаемый пакет не мешает
запуску приложения и работе с базовыми XML Schema типами. Неизвестное имя
возвращает `Неопределено`; неподдерживаемая декларация известного пакета
выдаёт явную ошибку. `Пакеты` запрашивает полный граф и потому может выявить
ошибку в пакете, который до этого не использовался.

Фабрика одна на source-приложение, включая его модули. Дескрипторы сохраняют
идентичность при загрузке следующего пакета. Ошибка загрузки не публикует
частично созданные типы и не портит ранее созданные значения. Разные
приложения имеют разные фабрики: чужой дескриптор не принимается.
`Новый ФабрикаXDTO` остаётся самостоятельной фабрикой базовых типов.

Для поддержанных типов доступны существующие создание значений, XML и JSON
чтение/запись. Поддерживаются простые атомарные aliases XML Schema и
нерекурсивные объектные типы с поддержанными свойствами. Внешние схемы и URI
не скачиваются; импорт должен указывать на пакет этой же конфигурации.
Неподдержанные facets, наследование и разновидности типов не угадываются.

Пределы: инвентарь до 256 деклараций, загруженный граф до 8 пакетов;
существующие общие пределы байтов схем, типов, свойств и глубины сохраняются.
Бюджет байтов и глубина проверяются также при последовательной загрузке.
После закрытия приложения новые обращения к его глобальной фабрике не
загружают пакеты. Уже созданные значения остаются обычными локальными
данными без прав на БД, сеть или файлы.

Проверка: `tests/test_source_xdto_packages.py` проверяет ленивое связывание,
импорты, атомарность, identity, XML/JSON, изоляцию, неоднозначные namespace,
ограничения и сохранение строгого профиля. Это локальные тесты; новый
нативный прогон source-binding на 1С не выполнялся. Исторические входные
пакеты используются без изменения и не выдаются за свежую native parity.

# Преобразование JSON-значений, даты и функции BSL

Это единый локальный прикладной слой поверх существующих `ЧтениеJSON` и
`ЗаписьJSON`: даты в документах, настройки сериализации, восстановление
объектов и преобразование неподдержанных типов экспортными функциями BSL.
Обработчики используют обычный диспетчер подпрограмм, а не второй интерпретатор.
Новая реализация основана на официальной документации; новый нативный замер
дополнительных возможностей пока не заявлен. Ранее измеренные обычные коллекции,
правило продвижения курсора и `null → Неопределено` сохраняются.

## Даты и настройки

- `ПрочитатьДатуJSON(Строка, Формат)` / `ReadJSONDate` возвращает `Дата`.
- `ЗаписатьДатуJSON(Дата, Формат, [ВариантЗаписи])` / `WriteJSONDate` возвращает строку.
- `ФорматДатыJSON / JSONDateFormat`: `ISO`, `JavaScript`, `Microsoft`.
- `ВариантЗаписиДатыJSON / JSONDateWritingVariant`: `ЛокальнаяДата / LocalDate`,
  `ЛокальнаяДатаСоСмещением / LocalDateWithOffset`, `УниверсальнаяДата / UniversalDate`.
- `Новый НастройкиСериализацииJSON / New JSONSerializerSettings` не принимает аргументов.
  Изменяемые свойства: `ВариантЗаписиДаты / DateWritingVariant`,
  `ФорматСериализацииДат / DateSerializationFormat`,
  `СериализовыватьМассивыКакОбъекты / SerializeArraysAsObjects`.

Обычные умолчания: ISO, локальная дата без смещения, массивы как массивы.
Они соответствуют примерам руководства; страницы конструктора справки не
перечисляют все умолчания отдельно. JavaScript использует строку `new Date(ms)`,
Microsoft — `/Date(ms)/`; это данные, не выполняемый JavaScript. Для этих двух
форматов требуется явно заданный `UniversalDate`. Обычный ISO имеет вид
`2024-01-02T03:04:05`, с `Z` или `±HH:MM` при соответствующем варианте.

Преобразования используют действующую автономную политику часового пояса
Yadinassi: `YADINASSI_TIMEZONE` либо местный пояс процесса. Настройка ОС не
меняется. Поддержаны целые секунды; неподтверждённые дробные даты, неоднозначные
и несуществующие местные времена и неподдерживаемые границы отклоняются явно.
Подробные ограничения находятся в модуле `json_dates.py` и его тестах.

## Запись и преобразование пользовательских значений

```bsl
Функция ПредставлениеJSON(Свойство, Значение, Дополнительно, Отказ) Экспорт
    Если Свойство = "ВнутреннийКлюч" Тогда
        Отказ = Истина;
        Возврат Неопределено;
    КонецЕсли;
    Возврат Строка(Значение);
КонецФункции

Функция ПолучитьJSON() Экспорт
    Данные = Новый Структура("Дата,Идентификатор", Дата(2024, 1, 2), Новый УникальныйИдентификатор);
    Запись = Новый ЗаписьJSON;
    Запись.УстановитьСтроку();
    ЗаписатьJSON(Запись, Данные, , "ПредставлениеJSON", ЭтотОбъект);
    Возврат Запись.Закрыть();
КонецФункции
```

`ЗаписатьJSON / WriteJSON` принимает шесть аргументов: writer, значение,
настройки, имя функции, модуль функции, дополнительные параметры. Функция
вызывается только для типов, не поддержанных напрямую. Ей передаются имя
свойства, исходное значение, дополнительные параметры и изменяемый `Отказ`.
Результат должен быть непосредственно сериализуемым; повторное преобразование
того же неподдержанного результата не выполняется. Неподдержанные вложенные
значения возвращённой коллекции могут иметь свои вызовы обработчика.

`Отказ = Истина` удаляет именованное свойство структуры/соответствия до записи
его имени. Начальное значение флага — `Ложь`. Отказ для корня или элемента
массива пока отклоняется, поскольку однозначного документированного поведения
не найдено. `Знач Отказ` подчиняется обычной передаче по значению.

Простые значения, даты, массивы, структуры, соответствия и их фиксированные
варианты обрабатываются одним проходом. Ключи соответствия должны быть строками.
Циклы отклоняются; повторно используемый ациклический объект допустим. Содержимое
каждого контейнера фиксируется перед его обходом, без глубокого копирования.
Готовое значение добавляется writer только после успешного преобразования;
явные побочные действия самого обработчика этим не отменяются.

## Чтение и восстановление

`ПрочитатьJSON / ReadJSON` принимает девять аргументов:

1. Reader.
2. Читать в соответствие (умолчание `Ложь`).
3. Имена свойств с датами: одно строковое имя, `Массив` или `ФиксированныйМассив`.
4. Ожидаемый формат даты (умолчание ISO).
5. Имя функции восстановления.
6. Модуль функции.
7. Дополнительные параметры.
8. Массив имён свойств для восстановления.
9. Максимальная вложенность (документированное умолчание 500).

```bsl
Функция Восстановить(Свойство, Значение, Дополнительно) Экспорт
    Если Свойство = "Идентификатор" Тогда
        Возврат Новый УникальныйИдентификатор(Значение);
    КонецЕсли;
    Возврат Значение;
КонецФункции
```

Функция получает уже восстановленные дочерние значения: сначала дети, затем
контейнер, корень последним. Для корня и элементов массива имя передаётся как
`Неопределено` (явная локальная политика для неименованных узлов). Имена JSON
сравниваются точно, без изменения регистра или разбиения строки по запятым.
При отсутствии фильтра обработчик вызывается для каждого узла. При наличии
фильтра — только для указанных имён. Выбранный обработчик имеет приоритет перед
автоматическим разбором даты, в том числе при отсутствии фильтра. Преобразование
дат по именам работает и без обработчика.

Пропуски необязательных аргументов поддержаны. Имена и модули функций указываются
вместе. Дополнительные объекты сохраняют обычную идентичность. Ошибки обработчиков
доступны обычному `Попытка/Исключение`, а состояние экспортного модуля сохраняется.
Можно вложенно вызывать JSON и обычные `RunCallback` в том же диспетчере.

## Границы

- Обработчик — обычная экспортная контекстная функция. Асинхронные обработчики,
  процедуры, NoContext, переход клиент/сервер и перенос модулей не поддержаны.
  Обычный JSON без обработчиков доступен с обеих сторон. Сам JSON-вызов можно
  использовать внутри асинхронного BSL-кода; неявного ожидания обработчика нет.
- Сохраняются пределы JSON: миллион символов и глубина 128; добавлен предел
  100000 посещённых значений. `MaximumNesting` может уменьшить глубину, но не
  отменяет предел реализации. Это ресурсная политика, не пределы платформы 1С.
- Настройки и значения новых перечислений не сериализуются внутренним кодеком
  и не предоставляют межконтекстный перенос или XDTO.
- `SerializeArraysAsObjects=True` пока отклоняется при записи: справка показывает
  индексы 1,2,3, руководство 0,1,2. Свойство доступно, но неоднозначный wire-формат
  не выбирается молча.
- Новые `ПрочитатьЗначениеJSON / ReadJSONValue` и `ЗаписатьЗначениеJSON / WriteJSONValue`
  не входят в блок. RU/EN справка противоречит сама себе по `Null/Undefined`.
- Не обещаются побайтовая идентичность всех представлений дат, частичных ошибок,
  локалей и иных клиентов, либо нативные результаты не проведённых измерений.

# Списки локального каталожного UI

Каталожный режим получает полный detached-снимок стандартных полей через логический backend: не более 8192 записей и 4 MiB. При превышении бюджета список отказывается открываться; усечённый набор не выдаётся за полный. Чтение и закрытие read lease завершаются до публикации снимка.

Поиск по коду и описанию нечувствителен к регистру (`casefold`), сортировка фиксирована по коду либо описанию. Это правила представления UI, а не обещание колляции платформы 1С. Перелистывание и поиск используют один снимок. **Refresh records** перечитывает внешние изменения; открытие карточки всегда читает объект заново.

Собственное сохранение обновляет список, сохраняя фильтр и сортировку. Если сохранённая запись не соответствует фильтру, она не подмешивается в выдачу: показывается отдельное сообщение. Исчезнувшая запись также обозначается отдельно. Ошибка обновления после подтверждённой записи требует повторного чтения, а не повторной записи.

Открытый редактор блокирует поиск и обновление списка, чтобы не заменить пользовательский черновик. Существующие проверки ревизии записи, импортированных форм и неопределённого исхода сохранения остаются обязательными.

## Выбор ссылок

Кнопка **Choose reference** открывает отдельный выбор с поиском по коду и описанию, страницами по 32 записи и явным обновлением вариантов. При открытии самой карточки выполняется только ограниченный просмотр первых 64 записей: малые справочники сохраняют обычный выпадающий список, для больших остаются текущее и пустое значения плюс ленивый выбор. Полный снимок вариантов создаётся по нажатию кнопки и подчиняется лимиту 8192/4 MiB; превышение означает явный отказ, а не частичный набор.

Билет выбора связан с конкретным редактором, реквизитом либо стабильной строкой табличной части, исходным значением и источником конфигурации. Сервер принимает только выданный вариант текущей страницы. Перед применением запись перечитывается; исчезнувшая или помеченная ссылка не применяется. Изменение владельца, строки, значения или завершение редактирования отзывает выбор. Применение меняет черновик через прежний типизированный обработчик, а запись в базу по-прежнему происходит только после Save.

Неподдерживаемые структуры табличных частей, отсутствующие текущие ссылки и ограничения импортированных форм не превращаются в редактируемые автоматически. Блок не распространяет разрешения configuration-UI на другие профили. Проверки Python/JS не заменяют отдельное подтверждение поведения модального окна в реальном браузере.

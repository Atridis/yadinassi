## Platform documentation checked during reconstruction

The official [form data types guide](https://kb.1ci.com/1C_Enterprise_Platform/Tutorials/Practical_developer_guide_8.3/Lesson_27._Form_development_techniques/Form_data_types/)
was reread on 2026-11-12. It distinguishes the form's data representation from the
applied object, and places the conversion methods in server form procedures.
Therefore observe enum fields themselves for value type/empty identity; do not
use TypeOf(Object) as proof of its metadata-declared CatalogObject/DocumentObject
type. The authored conversion bridge will execute at server and remain labelled
separately from the platform's standard form command processing.


The official [parameterized command guide](https://kb.1ci.com/1C_Enterprise_Platform/Tutorials/Practical_developer_guide_8.3/Lesson_27._Form_development_techniques/Using_parameterized_commands/In_Designer_mode/?language=en)
identifies the fourth OpenForm argument as the uniqueness control. The packet
uses True but accepts independence only with both instances' actual create/open
witnesses preceding either authored observation. An argument alone is not proof.

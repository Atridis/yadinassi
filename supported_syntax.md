# Поддерживаемые объекты и функции

Текущий справочник встроенных типов, коллекций и глобальных функций Yadinassi.
Он описывает доступное подмножество API, а не полную совместимость с платформой
1С. Базовый синтаксис и устройство примитивных типов здесь не рассматриваются.
История расширения возможностей и примеры находятся в [features.md](features.md),
неподдерживаемые объекты — в [unsupported_syntax.md](unsupported_syntax.md).

Русские и английские имена ниже равноправны и нечувствительны к регистру.
В сигнатурах квадратные скобки обозначают необязательные аргументы, а `...` —
повторяющиеся аргументы. Это обозначения справочника, не текст программы.
Перечислены встроенные возможности обычного интерпретатора; объекты и функции,
добавленные приложением через Python API, в этот список не входят.

## Коллекции

### Массив / Array

Конструкторы: `Массив()`, `Массив(Размер [, Размер2, ...])`,
`Массив(ФиксированныйМассив)`.

- Чтение и запись по индексу, обход элементов. Индексы начинаются с нуля.
- `Количество / Count()`, `ВГраница / UBound()`, `Получить / Get(Индекс)`,
  `Найти / Find(Значение)`.
- `Добавить / Add([Значение])`, `Вставить / Insert(Индекс [, Значение])`,
  `Установить / Set(Индекс, Значение)`, `Удалить / Delete(Индекс)`,
  `Очистить / Clear()`.
- Пропущенное значение при добавлении или вставке — `Неопределено`.
  Вставка за текущей границей дополняет промежуток `Неопределено`.
  Чтение, запись и `Удалить / Delete` требуют существующего индекса.
  Удаление из пустого массива или выше `ВГраница()` вызывает ошибку,
  не меняя содержимое (нативный результат 1С 8.3.27.2342, Windows, ru-RU).
  Отрицательные, дробные и нечисловые индексы также отклоняются.
- `ВГраница()` пустого массива возвращает `-1`, неудачный поиск — `Неопределено`.
- Многомерный массив состоит из отдельных вложенных массивов. Размеры целые,
  неотрицательные; при нескольких измерениях все размеры должны быть положительными.
  Лимиты конструктора Yadinassi: 64 измерения и суммарно 1 000 000 ячеек
  и вложенных массивов. Рост за одну вставку ограничен 1 000 000 элементов.
- Копирование из фиксированного массива рекурсивно преобразует непосредственно
  вложенные фиксированные массивы в изменяемые; другие значения сохраняют ссылки.

### ФиксированныйМассив / FixedArray

Конструктор: `ФиксированныйМассив(Массив)`.

- Чтение по индексу, обход, `Количество / Count()`, `ВГраница / UBound()`,
  `Получить / Get(Индекс)`, `Найти / Find(Значение)`.
- Запись элементов и изменяющие методы отсутствуют.
- Непосредственно вложенные изменяемые массивы также преобразуются в фиксированные.
  Структуры, соответствия и уже фиксированные массивы сохраняют ссылки:
  это не универсальная глубокая заморозка графа объектов.
  Циклы из непосредственно вложенных изменяемых массивов отклоняются.

### Структура / Structure

Конструкторы: `Структура()`, `Структура(ИменаСвойств [, Значения...])`,
`Структура(ФиксированнаяСтруктура)`.

- Имена в конструкторе разделяются запятыми; отсутствующие значения — `Неопределено`.
- Чтение и запись существующего свойства через точку или индекс с именем свойства.
  Имена свойств нечувствительны к регистру и должны быть допустимыми идентификаторами.
- `Количество / Count()`, `Свойство / Property(Имя [, Значение])`.
  `Свойство` возвращает признак наличия и может записать найденное значение
  во второй аргумент; для отсутствующего свойства записывает `Неопределено`.
- `Вставить / Insert(Имя [, Значение])`, `Удалить / Delete(Имя)`, `Очистить / Clear()`.
  Вставка создает или заменяет свойство. Удаление отсутствующего свойства допустимо.
- Обход дает пары `КлючИЗначение`. Изменение состава структуры во время обхода
  не поддерживается; замена значений существующих свойств не меняет состав.

### ФиксированнаяСтруктура / FixedStructure

Конструкторы: `ФиксированнаяСтруктура()`,
`ФиксированнаяСтруктура(ИменаСвойств [, Значения...])`,
`ФиксированнаяСтруктура(Структура)`.

- Чтение свойств через точку или индекс, обход пар `КлючИЗначение`,
  `Количество / Count()`, `Свойство / Property(Имя [, Значение])`.
- Свойства недоступны для записи, изменяющие методы отсутствуют.
  Состав копируется, вложенные значения сохраняют ссылки.

### Соответствие / Map

Конструкторы: `Соответствие()`, `Соответствие(ФиксированноеСоответствие)`.

- Чтение и запись по ключу, обход пар `КлючИЗначение`.
- `Количество / Count()`, `Получить / Get(Ключ)`,
  `Вставить / Insert(Ключ [, Значение])`, `Удалить / Delete(Ключ)`, `Очистить / Clear()`.
- Отсутствующий ключ при чтении дает `Неопределено`; запись создает или заменяет
  элемент, удаление отсутствующего ключа допустимо.
- Тип ключа значим; ключи-коллекции сопоставляются по идентичности объекта.
  Порядок обхода не является гарантией совместимости с 1С.
  Изменение состава при обходе не поддерживается.

### ФиксированноеСоответствие / FixedMap

Конструктор: `ФиксированноеСоответствие(Соответствие)`.

- Чтение по ключу, обход пар `КлючИЗначение`, `Количество / Count()`,
  `Получить / Get(Ключ)`.
- `Получить` отсутствующего ключа возвращает `Неопределено`, но индексное чтение
  отсутствующего ключа вызывает ошибку.
- Запись элементов и изменяющие методы отсутствуют.
  Состав копируется, вложенные значения сохраняют ссылки.

## Служебные типы и системные перечисления

- `КлючИЗначение / KeyAndValue`: элемент обхода структуры или соответствия.
  Свойства `Ключ / Key` и `Значение / Value` доступны только для чтения.
  Конструктора `Новый КлючИЗначение` нет.
- `Тип / Type`: непрозрачное значение, получаемое через `Тип(Имя)` или
  `ТипЗнч(Значение)`. Поддержаны сравнение и использование как ключа соответствия.
  Это не описание метаданных и не `ОписаниеТипов`; конструктора `Новый Тип` нет.
- `РежимОкругления / RoundMode`: глобальное пространство значений
  `Окр15как10 / Round15as10` и `Окр15как20 / Round15as20`, доступных только для чтения.
  Тип отдельного значения — `РежимОкругления / RoundMode`, тип самого пространства —
  `ПеречислениеРежимОкругления / EnumRoundMode`. Обход пространства дает два значения
  в указанном порядке. Отдельных конструкторов для них нет.
- `НаправлениеПоиска / SearchDirection`: глобальное пространство значений
  `СНачала / FromBegin` и `СКонца / FromEnd`, доступных только для чтения.
  Обход дает эти два значения в указанном порядке; их строковые представления —
  `С начала` и `С конца`. Значения различаются, не равны числам или значениям
  другого перечисления и могут быть ключами соответствия. Конструкторов нет.
  `Тип("НаправлениеПоиска")` и `Type("SearchDirection")` дают тип значения.
  Тип самого пространства получается через `ТипЗнч(НаправлениеПоиска)`;
  его строковое представление — `ПеречислениеНаправлениеПоиска`.
  Поиск типа по именам `ПеречислениеНаправлениеПоиска` / `EnumSearchDirection`
  отклоняется, хотя значение типа пространства поддержано внутренним кодеком.

Наличие типа не означает, что каждая глобальная функция принимает его.
Ограничения отдельных функций приведены ниже.

## Глобальные функции и процедуры

### Типы, значения и диагностика

- `Тип / Type(Имя)`, `ТипЗнч / TypeOf(Значение)` — для перечисленных выше встроенных
  типов, а также примитивных значений интерпретатора. Исключение поиска по имени —
  тип пространства `НаправлениеПоиска`, описанный выше. Неизвестные типы отклоняются;
  эти функции не открывают доступ к отсутствующим объектам платформы.
- `Строка / String(Значение)`, `Число / Number(Значение)`,
  `Булево / Boolean(Значение)` — встроенные преобразования.
- `ЗначениеЗаполнено / ValueIsFilled(Значение)` — для примитивных значений и шести
  коллекций выше. Для коллекций проверяет непустой состав; для `Тип`,
  `КлючИЗначение`, значений и пространств системных перечислений пока не поддерживается.
- `ЗаполнитьЗначенияСвойств / FillPropertyValues(Приемник, Источник
  [, СписокСвойств, ИсключаемыеСвойства])` — процедура только для структур
  и фиксированных структур. Копирует значения, не добавляя свойства приемника.
  Списки заполнения и исключения нельзя применять одновременно; в списках
  не поддержаны пустые имена и окружающие пробелы. Фиксированный приемник без
  списков остается неизменным, со списками отклоняется.
- `Сообщить / Message(Значение)` — вывод одного значения.
- `ОписаниеОшибки / ErrorDescription()` — описание обрабатываемой ошибки,
  вне обработчика — пустой результат.
- `Вычислить / Eval(Выражение)` — вычисление одного выражения в текущем контексте.
  Принимает текст или конечное число; пределы Yadinassi: 65 536 символов
  и 16 вложенных вызовов. Не заменяет отсутствующие типы и функции платформы.

### Работа с текстом

Здесь перечислен API функций, без описания примитивного типа и его синтаксиса.

- `СтрДлина / StrLen(Текст)`.
- `Символ / Char(Код)`, `КодСимвола / CharCode(Текст [, Позиция = 1])`.
- `Лев / Left(Текст, Количество)`, `Прав / Right(Текст, Количество)`,
  `Сред / Mid(Текст, Начало [, Количество])`.
- `Найти / Find(Текст, Подстрока)` — прямой поиск первого вхождения.
- `СтрНайти / StrFind(Текст, Подстрока [, Направление, Начало, НомерВхождения])`.
  Поиск чувствителен к регистру, без нормализации Unicode; результат — позиция
  первого символа совпадения от 1 или 0, если нужного вхождения нет.
  Направление по умолчанию — `НаправлениеПоиска.СНачала`; обратное направление —
  `НаправлениеПоиска.СКонца`. Начало по умолчанию — 1 или длина строки
  соответственно; для пустого текста — 1. У обратного поиска начало ограничивает
  позицию первого символа совпадения, а не последнего. Номер вхождения по умолчанию —
  1; непустые совпадения считаются без пересечений от выбранной начальной позиции.
  Дробные позиции и номера усекаются к нулю; числовые строки принимаются.
  Явная позиция должна попадать в `1..Макс(1, СтрДлина(Текст))` после усечения.
  Нулевой номер отклоняется, отрицательный возвращает 0.
  Явное `Неопределено` вместо начала использует умолчание;
  вместо направления или номера вхождения оно отклоняется. Пустые необязательные
  позиции между запятыми используют умолчания; первые два аргумента обязательны.
  Для пустой подстроки после проверки аргументов номер 1 дает 1, положительный
  номер больше 1 — нормализованное начало. Нативно проверены отдельные случаи
  с номерами 1, 2, 3; обобщение на остальные комбинации — правило реализации,
  а не исчерпывающая проверка 1С. Подробности и примеры — в `features.md`.
  `Найти / Find` дополнительных параметров не имеет.
- `СтрЗаменить / StrReplace(Текст, Подстрока, Замена)`.
- `СтрНачинаетсяС / StrStartsWith(Текст, Подстрока)`,
  `СтрЗаканчиваетсяНа / StrEndsWith(Текст, Подстрока)`.
- `СокрЛ / TrimL(Текст)`, `СокрП / TrimR(Текст)`, `СокрЛП / TrimAll(Текст)`,
  `ПустаяСтрока / IsBlankString(Текст)`.
- `ВРег / Upper(Текст)`, `НРег / Lower(Текст)`.
- `СтрРазделить / StrSplit(Текст, Разделители [, ВключатьПустые = Истина])` — массив;
  разделители трактуются как набор символов.
- `СтрСоединить / StrConcat(Массив [, Разделитель = ""])` — принимает также
  фиксированный массив.
- `СтрЧислоВхождений / StrOccurrenceCount(Текст, Подстрока)`.
- `СтрЧислоСтрок / StrLineCount(Текст)`, `СтрПолучитьСтроку / StrGetLine(Текст, Номер)`.
- `СтрШаблон / StrTemplate(Шаблон [, Значения...])` — до десяти значений,
  маркеры `%1`–`%10`, `%(1)`–`%(10)` и `%%`.
- `СтрСравнить / StrCompare(ПервыйТекст, ВторойТекст)` — сравнение без учета регистра,
  результат `-1`, `0` или `1`; аргументы должны быть текстовыми.

Позиции и длины текстовых функций считаются в кодовых единицах UTF-16, позиции
начинаются с единицы. Реализованное сравнение и преобразование регистра не означает
поддержку всех локалей платформы; границы совместимости описаны в `features.md`.

### Числовые и побитовые функции

- `Цел / Int(Значение)`.
- `ЧислоИзДвоичнойСтроки / NumberFromBinaryString(Текст)`,
  `ЧислоИзШестнадцатеричнойСтроки / NumberFromHexString(Текст)` — точное число
  из ASCII-цифр со строго строчными префиксами `0b` / `0x`. Ноль и начальные
  нули разрешены; шестнадцатеричные цифры нечувствительны к регистру.
  Пробелы, знаки, дроби и посторонние символы не допускаются; аргумент текстовый.
  Нативно подтверждены значения до максимума 128 бит (39 десятичных цифр).
  Локальный предел: 4096 двоичных или 1024 шестнадцатеричных цифр, включая
  начальные нули; он не является заявлением о нативной максимальной разрядности.
- `Мин / Min(ПервоеЗначение [, Значения...])`,
  `Макс / Max(ПервоеЗначение [, Значения...])` — минимум один аргумент;
  либо текстовые аргументы, либо числовые/булевы. Возвращают исходный выбранный
  аргумент, при равенстве — первый.
- `Окр / Round(Значение [, Разрядность = 0, Режим = РежимОкругления.Окр15как20])` —
  принимает значения системного перечисления или числовой режим.
- `ПобитовоеИ / BitwiseAnd(Первое, Второе)`,
  `ПобитовоеИли / BitwiseOr(Первое, Второе)`,
  `ПобитовоеИсключительноеИли / BitwiseXor(Первое, Второе)`,
  `ПобитовоеИНе / BitwiseAndNot(Первое, Второе)`,
  `ПобитовоеНе / BitwiseNot(Значение)`.
- `ПроверитьБит / CheckBit(Значение, Позиция)`,
  `ПроверитьПоБитовойМаске / CheckByBitMask(Значение, Маска)`,
  `УстановитьБит / SetBit(Значение, Позиция, Установлен)`.
- `ПобитовыйСдвигВправо / BitwiseShiftRight(Значение, Смещение)` — беззнаковый
  сдвиг с заполнением нулями.
- `ПобитовыйСдвигВлево / BitwiseShiftLeft(Значение, Смещение)` — сдвиг
  с отбрасыванием старших битов за границей 32 бит.

Побитовые операции принимают целые числа `0..4294967295`, позиции и смещение —
`0..31`; `Установлен` должен быть булевым. Неявные преобразования других типов
не поддержаны. Переполнение сдвига влево подтверждено нативными пробами PR52.

### Преобразования XML

- `XMLСтрока / XMLString(Значение)`.
- `XMLЗначение / XMLValue(ТипЗначения, Текст)`.

Поддержаны только текстовые и булевы значения. Это лексические преобразования,
не чтение/запись XML-документов: XML-сущности и экранирование не обрабатываются.

### Внутреннее представление значений

- `ЗначениеВСтрокуВнутр / ValueToStringInternal(Значение)`.
- `ЗначениеИзСтрокиВнутр / ValueFromStringInternal(Представление)`.

Поддержаны примитивные значения, шесть коллекций выше, `КлючИЗначение`, `Тип`,
значения и пространства `РежимОкругления` и `НаправлениеПоиска`.
Значения перечислений восстанавливаются как те же значения; записи самих
пространств при обратном чтении дают `Неопределено` согласно нативным пробам.
Их отдельные записи `Тип` сохраняют идентичность соответствующего типа,
включая тип пространства, недоступный через `Тип(Имя)`.
Поддержка ограничена реализованными формами внутреннего потока 1С: это не JSON
и не обещание совместимости с произвольным внутренним представлением платформы.
Циклы и неизвестные теги отклоняются; общая идентичность повторяющихся вложенных
объектов не сохраняется как граф ссылок.

Лимиты кодека Yadinassi: 1 048 576 символов представления, глубина 64,
10 000 узлов и 4 096 десятичных разрядов для числового представления.
Это защитные ограничения реализации, а не заявленные пределы платформы 1С.

## Основание справочника

Регистрация API: [runtime.py](yadinassi/runtime.py). Реализация объектов:
[values.py](yadinassi/values.py), [structures.py](yadinassi/structures.py),
[maps.py](yadinassi/maps.py), [type_values.py](yadinassi/type_values.py),
[round_modes.py](yadinassi/round_modes.py),
[search_directions.py](yadinassi/search_directions.py). Функции:
[strings.py](yadinassi/strings.py), [numbers.py](yadinassi/numbers.py),
[bits.py](yadinassi/bits.py), [value_checks.py](yadinassi/value_checks.py),
[xml_values.py](yadinassi/xml_values.py), [serialization.py](yadinassi/serialization.py).
Проверки находятся в [tests](tests); подтвержденные ручные прогоны 1С —
в [integrational_tests](integrational_tests). Наличие локального теста само по себе
не означает, что все варианты вызова проверены на реальной 1С.
